# HitboxPad
Open this folder in Android Studio (it creates the Gradle wrapper), run on a physical Android 9+ phone/tablet.
1. On the Switch: Controllers > Change Grip/Order (leave it open).
2. In the app: Bluetooth > "Pair new device", pair with the Switch in Android settings, come back,
   Bluetooth > tap the Switch in the list.
3. Use "Edit buttons" to remap the 12 purple buttons.
Switch 2: same steps (Controllers > Connect Controllers). Untested – see notes.
